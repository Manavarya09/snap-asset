FEATURES
FEATUREDESCRIPTION
Element Capturetarget specific DOM elements via CSS selector. captures exactly the element at native resolution with transparent or solid background.
Site Extractioncrawl and capture entire website -- sections, images, and components in one pass. outputs organized directory with manifest file.
Component Isolationrender react/vue/svelte components in isolation with transparent backgrounds at any viewport size. no page chrome.
Auto-Optimizegenerates png (lossless) + webp (lossy) formats simultaneously at retina 2x resolution. balances quality vs file size.
Batch Modedefine multiple captures in snap-asset.config.json. run all with a single command. supports multiple selectors per page.
Dark Modecapture with prefers-color-scheme:dark. ideal for dark-themed portfolio screenshots and documentation pages.

INSTALLATION

  $ git clone https://github.com/Manavarya09/snap-asset.git
  $ cd snap-asset
  $ npm install
  $ npx snap-asset --help
===========================================================================================================================================================================================================================================================================================================================================================================================================================================================================================================
USAGE EXAMPLES

  $ snap-asset https://example.com --name homepage
  > saved: assets/homepage.png (1200x800)
  > saved: assets/homepage.webp (1200x800)

  $ snap-asset https://example.com --selector ".hero-section" --name hero
  > saved: assets/hero.png (900x400)
  > saved: assets/hero.webp (900x400)

  $ snap-asset extract https://docsite.com --out public/assets
  > manifest: public/assets/manifest.json
  > extracted: 47 assets across 12 pages

  $ snap-asset component ./src/components/Button.tsx --name button
  > saved: assets/button.png (200x48)
  > saved: assets/button.webp (200x48)

  $ snap-asset batch
  > config: snap-asset.config.json
  > batch complete: 12/12 captures successful
===========================================================================================================================================================================================================================================================================================================================================================================================================================================================================================================
CLI REFERENCE
COMMAND/FLAGDESCRIPTION
snap-asset <url>capture full-page screenshot of the given URL
--name <string>output filename (without extension)
--selector <css>capture element matching CSS selector
--darkenable dark color scheme (prefers-color-scheme:dark)
--width <px>viewport width (default: 1920)
--height <px>viewport height (default: 1080)
snap-asset extract <url>extract all site assets from URL recursively
--out <dir>output directory for extracted assets (default: assets/)
snap-asset component <file>render and capture component in headless isolation
snap-asset batchrun all captures defined in snap-asset.config.json
