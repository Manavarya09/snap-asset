COMMANDS
COMMANDDESCRIPTION
snap-asset <url>capture URL screenshot (default command)
snap-asset extract <url>extract all site assets recursively
snap-asset component <file>render and capture component in isolation
snap-asset batchrun all captures from snap-asset.config.json
snap-asset servestart HTTP server for interactive capture
snap-asset initgenerate starter snap-asset.config.json
================================================================================
CAPTURE (21)
FLAGDESCRIPTION
-n, --name <name>output filename (without extension)
-s, --selector <css>capture element matching CSS selector
-w, --width <px>viewport width (default 1280)
-h, --height <px>viewport height (default 800)
--scale <n>device scale factor (default 2)
--resize <WxH>resize after capture e.g. 800x600
--clip <x,y,w,h>crop capture to rectangular region
--wait <ms>wait before capture (default 0)
--darkemulate dark color scheme
--full-pagecapture full scrollable page
--overwriteoverwrite existing output files
--wait-for-lazywait for lazy-loaded images before capture
--wait-for-selector <s>wait for CSS selector before capture
--before-capture <json>JSON array of interaction actions
--css <code>inject CSS into the page
--retries <n>retry count for failed captures (default 2)
--no-cachedisable disk cache
--cookies <path>JSON file with cookies array
--login-script <path>JS module exporting default async login(page)
--batch-file <path>file with newline-separated URLs to capture
--auth <credentials>HTTP authentication (username:password)
================================================================================
PDF (5)
FLAGDESCRIPTION

EMULATION (8)
FLAGDESCRIPTION

EXAMPLES

$ snap-asset https://example.com --name homepage
  saved: assets/homepage.png (1200x800)
  saved: assets/homepage.webp (1200x800)

$ snap-asset https://example.com --selector ".hero" --name hero --dark
  saved: assets/hero.png (900x400)
  saved: assets/hero.webp (900x400)

$ snap-asset extract https://docsite.com --out public/assets
  manifest: public/assets/manifest.json
  extracted: 47 assets across 12 pages

$ snap-asset component ./src/Button.tsx --name button --width 200 --height 48
  saved: assets/button.png (200x48)
  saved: assets/button.webp (200x48)

$ snap-asset https://example.com --pdf --pdf-format A4 --out pdfs
  saved: pdfs/example.pdf (42 KB)

$ snap-asset https://example.com --device "iPhone 15" --full-page --format webp
  saved: assets/example.webp (390x844)

$ snap-asset batch --concurrency 5
  config: snap-asset.config.json
  batch complete: 12/12 captures successful
